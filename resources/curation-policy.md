# Resource Curation Policy

## Acceptance criteria

A resource must:

1. support a named roadmap outcome;
2. be authoritative or show exceptional pedagogical value;
3. contain runnable, reasonably current material;
4. have stable access and no piracy concern;
5. state prerequisites clearly enough for correct placement;
6. add value not already covered by the primary resource.

Prefer official documentation, original courses/papers, respected educational
institutions, and maintained repositories.

## Submission format

- Name and URL
- Roadmap stage and exact outcome
- Intended learner level
- Format and estimated time
- Access/cost and license where relevant
- Maintenance evidence (recent release/commit or still-valid fundamentals)
- Why it should be added or what it should replace
- Any conflicts, tracking, affiliate relationship, or authorship

## Reasons to reject

- unranked “top resources” lists;
- affiliate/lead-generation links;
- pirated books/courses or unclear redistribution;
- inaccessible material with no exceptional justification;
- abandoned code that no longer runs;
- duplicate coverage;
- exaggerated claims or benchmark-only teaching;
- unsafe guidance or undocumented data use.

## Review cadence

Review core links at least twice yearly and fast-moving GenAI/provider resources
quarterly. Mark temporarily unavailable links; replace them after confirming the
issue is persistent. Use permanent documentation roots when deep links are unstable.
