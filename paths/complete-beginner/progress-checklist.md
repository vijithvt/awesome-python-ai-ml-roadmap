# Complete Beginner Progress Checklist

Link every checked item to evidence in your learning log.

## Orientation

- [ ] I selected a provisional target role.
- [ ] I documented weekly time, budget and constraints.
- [ ] I can explain AI, ML, deep learning and GenAI differences.
- [ ] I understand the AI-assisted learning protocol.

## Developer workflow

- [ ] I can navigate and operate from a terminal.
- [ ] I can clone, branch, commit, merge and resolve a simple conflict.
- [ ] I use isolated environments and locked dependencies.
- [ ] I never commit secrets.
- [ ] Another learner reproduced my starter repository.

## Python

- [ ] I use core types and collections appropriately.
- [ ] I decompose work into clear functions/modules.
- [ ] I process files and APIs with error handling.
- [ ] I write useful unit/integration tests.
- [ ] I use logging, typing and documentation.
- [ ] My Data Quality CLI passes the project gate.

## Data and SQL

- [ ] I use NumPy/pandas without hidden notebook state.
- [ ] I validate missing, duplicate, type, range and join assumptions.
- [ ] I write joins, CTEs and window functions.
- [ ] I select charts based on the question and data.
- [ ] I communicate uncertainty and limitations.
- [ ] My analysis case study is reproducible.

## Math and ML

- [ ] I can implement linear/logistic regression and gradient descent at learning scale.
- [ ] I establish a baseline.
- [ ] I choose a valid split and prevent leakage.
- [ ] I use pipelines for preprocessing/modeling.
- [ ] I select metrics and thresholds from error costs.
- [ ] I perform slice and qualitative error analysis.
- [ ] My ML project has a model card.

## Deep learning and GenAI

- [ ] I can write and debug a PyTorch training loop.
- [ ] I compare transfer learning to a simpler baseline.
- [ ] I understand tokens, embeddings, attention and transformers.
- [ ] I validate structured LLM output.
- [ ] I evaluate retrieval and answer quality separately.
- [ ] I test injection, privacy and permission risks.

## Production

- [ ] I serve a model/workflow through a tested API or batch interface.
- [ ] I containerize and run it in a clean environment.
- [ ] CI checks tests and quality.
- [ ] I identify data/model/config versions.
- [ ] I measure latency, throughput/memory and cost where relevant.
- [ ] I define monitoring, alert, fallback and rollback behavior.

## Career evidence

- [ ] I analysed at least 20 target JDs.
- [ ] I have 3–4 role-aligned, reproducible projects.
- [ ] My GitHub profile and resume pass peer review.
- [ ] I can give 2-, 10- and 30-minute project explanations.
- [ ] I practise Python, SQL, ML/system and behavioral interviews.
- [ ] Any certification I pursue is justified by target-role evidence.
