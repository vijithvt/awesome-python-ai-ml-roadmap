# Beginner Starting Diagnostic

This is a placement tool, not an exam. Use no tutorial or AI-generated solution.
Documentation is allowed unless the task says otherwise.

## Part A — Digital workflow

- Create folders and files from a terminal.
- Install Python and print its version.
- Clone a GitHub repository, create a branch, commit a change and merge it.
- Explain the difference between a file path, URL, environment variable and secret.

**Score:** one point each. Fewer than three means begin at Week 0.

## Part B — Programming

Write a Python program that reads a text file and prints the five most common words.
It must:

- ignore letter case and punctuation;
- handle a missing file cleanly;
- have at least three functions;
- include three automated tests;
- include run instructions.

| Evidence | Points |
| --- | ---: |
| Correct result | 2 |
| Functions and clear names | 1 |
| Error handling | 1 |
| Tests | 2 |
| README and Git history | 2 |

**0–3:** start Python from Week 2.  
**4–6:** use the faster exercises but complete the Python project.  
**7–8:** move to the data diagnostic.

## Part C — Data and SQL

Given two CSV tables—customers and orders:

1. identify invalid/missing data;
2. calculate monthly revenue and top customers;
3. join the tables in SQL;
4. create two appropriate charts;
5. write three findings and two limitations.

**Pass condition:** reproducible code/queries, correct joins, defensible charts and no
unsupported claims. A pass allows you to start at the math/ML foundation, but retain
the data case study in your portfolio.

## Part D — ML concepts

Explain in plain language:

1. feature versus target;
2. training, validation and test data;
3. overfitting;
4. data leakage;
5. precision versus recall;
6. why a baseline matters.

Then train a scikit-learn pipeline on a small tabular dataset and report a justified
metric plus error analysis.

Passing this part allows you to begin deep learning or a specialization. Do not skip
software, project, responsible-AI, or production checkpoints.

## Part E — Career constraints

Write down:

- target role and two alternative roles;
- hours available weekly;
- current computer/internet limitations;
- preferred domain;
- local/remote/international job target;
- degree or eligibility constraints;
- budget for courses, exams and cloud usage;
- deadline and why it matters.

Use these answers to select resources. Never buy a certificate before you know which
role and market it supports.
