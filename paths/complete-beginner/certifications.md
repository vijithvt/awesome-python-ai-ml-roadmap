# Certification Map for Beginners

Certifications are optional accelerators, not substitutes for projects. Choose one
foundation credential or one role-aligned credential—not all of them.

## Decision order

1. Select a target role and geography.
2. Review at least 20 suitable job descriptions.
3. Count explicitly named providers/credentials.
4. Build one project using the related skills.
5. Take the credential only if it improves structure, screening, employer/partner
   requirements, or confidence enough to justify cost and renewal.

| [GitHub Foundations](https://learn.microsoft.com/en-us/credentials/certifications/github-foundations/) | Weeks 8–16 | all technical roles | Paid exam; regional price | Git/GitHub, collaboration, projects, security | must still show real Git history |

| [Microsoft Azure AI Fundamentals](https://learn.microsoft.com/en-us/credentials/certifications/azure-ai-fundamentals/) | Weeks 36+ | Azure-facing beginners | Paid exam; regional price | AI concepts and Azure AI capability | exam codes/content can transition; verify current page |

## Role-aligned credentials after projects

| Credential | Suitable role | Attempt after | Readiness evidence first |
| --- | --- | --- | --- |
| [Google Professional ML Engineer](https://cloud.google.com/learn/certification/machine-learning-engineer) | ML engineer on Google Cloud | production capstone + cloud practice | pipelines, serving, monitoring and Python/SQL |
| [AWS Certified Machine Learning Engineer – Associate](https://aws.amazon.com/certification/certified-machine-learning-engineer-associate/) | ML/MLOps on AWS | hands-on AWS ML deployment | end-to-end AWS model lifecycle |
| [Microsoft Azure Data Scientist Associate](https://learn.microsoft.com/en-us/credentials/certifications/azure-data-scientist/) | Azure data scientist | classical ML project + Azure ML labs | experiment, train, deploy and monitor |
| [NVIDIA Generative AI LLM Associate](https://www.nvidia.com/en-us/learn/certification/generative-ai-llm-associate/) | LLM/GenAI practitioner | evaluated LLM capstone | prompting, LLM integration, evaluation, deployment |
| [Databricks certifications](https://www.databricks.com/learn/certification) | data/ML platform roles | Spark/lakehouse project | data processing and ML workflows on platform |

Provider offerings, exam codes, retirement dates, language, price and validity change.
Always use the official page on registration day.

## Course certificate versus certification

| Type | Meaning |
| --- | --- |
| Completion certificate | confirms you completed course requirements |
| Digital badge | provider-defined proof of a smaller skill/learning experience |
| Proctored certification | verifies performance against an exam blueprint |
| Applied credential | verifies completion of a practical assessment/lab |
| Academic certificate/degree | institution-defined curriculum and assessment |

Do not describe a course certificate as a professional certification.

## Recommended combinations

### Zero-budget learner

IBM SkillsBuild badge + three strong GitHub projects + open-source contribution.

### Data analyst

Portfolio first. Add a BI/cloud/data credential only when it appears in target JDs.
SQL and business communication normally matter more than an AI fundamentals badge.

### Junior data scientist

Classical ML portfolio first. Add a cloud data-science credential after hands-on labs.

### ML engineer

GitHub/software evidence + one cloud ML credential aligned with target employers.

### GenAI engineer

Evaluated RAG/LLM system first. Add NVIDIA, AWS or Azure credential only if the
provider aligns with the target market.

## Certification anti-patterns

- listing ten badges but no runnable project;
- taking advanced cloud exams with no cloud application;
- using exam dumps or violating exam policy;
- hiding expiry/renewal status;
- purchasing due to influencer affiliate pressure;
- assuming global recognition without checking local JDs;
- spending cloud money without budgets and alerts.
