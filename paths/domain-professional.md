# Path — Domain Professional

Use this if your strength is in healthcare, finance, manufacturing, education,
telecom, law, arts, operations, or another domain.

**Expected duration:** 4–6 months for applied prototyping; longer for engineering depth.

## Choose your operating level

| Goal | Learn deeply | Collaborate on |
| --- | --- | --- |
| AI-aware leader | problem framing, metrics, data/risk, evaluation | implementation |
| Analyst/automator | Python, SQL, data, APIs, LLM workflows | production operations |
| Domain AI builder | core roadmap through ML plus specialization | advanced infrastructure |
| Career switch | complete core and production capstone | none of the fundamentals |

1. [Start here](../roadmap/00-start-here.md)

## Domain-first project discovery

Document:

1. a repeated, costly decision or workflow;
2. current users and failure points;
3. available/collectable data and permission;
4. the simplest non-AI baseline;
5. error costs and required human oversight;
6. adoption and integration constraints;
7. a two-week proof-of-value experiment.

Do not begin from “Where can I use an LLM?” Begin from a measurable need.

## Safety boundary

For high-impact decisions, use qualified domain, legal, privacy, security, and ML
review. A learning project must not be deployed as an autonomous decision maker.
