# Code of Conduct

We are committed to a respectful, harassment-free learning community.

Be constructive, patient with beginners, evidence-led in technical disagreement,
and respectful of different backgrounds and access constraints. Do not demean,
harass, discriminate, expose private information, or promote unsafe or plagiarized
work.

Report unacceptable behavior privately to the repository owner through an
appropriate GitHub contact channel. Maintainers may edit or remove contributions and
restrict participation when necessary to protect the community.
