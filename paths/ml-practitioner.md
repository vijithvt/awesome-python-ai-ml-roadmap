# Path — ML Practitioner to Modern AI

Use this if you already train/evaluate classical models.

**Expected duration:** 3–5 months.

## Diagnostic

You should be able to demonstrate pipelines without leakage, metric selection,
calibration/thresholding, experiment tracking, error slices, and deployment of at
least one model. Repair gaps in [Stage 4](../roadmap/04-machine-learning.md).

## Route

1. [Deep learning](../roadmap/05-deep-learning.md), skipping only proven skills
2. One specialization:
   - [LLMs/GenAI](../roadmap/06-llms-and-genai.md)
   - [Computer vision](../roadmap/07-computer-vision.md)
3. [MLOps/production](../roadmap/08-mlops-production.md)
4. [Portfolio/career](../roadmap/09-portfolio-career.md)

## Depth requirements

- reproduce or extend one influential paper/technique;
- run controlled ablations, not only model comparisons;
- build a fixed evaluation set and regression suite;
- analyze robustness and subgroup behavior;
- report compute, latency, memory, and cost;
- contribute a bug fix, example, evaluation, or documentation improvement upstream.

## Capstone

Build a system whose value comes from evaluation and operational quality—not merely
calling a model. Publish an architecture decision record explaining model/provider,
data, retrieval/fine-tuning, safety, and deployment trade-offs.
