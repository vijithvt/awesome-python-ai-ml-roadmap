# Curated Resource Index

Resources are mapped to stages so learners can follow a primary route instead of
collecting courses. Free-to-access resources are prioritized; some may offer optional
paid certificates.

## Foundations

| Resource | Best for | Stage |
| --- | --- | --- |
| [Python Tutorial](https://docs.python.org/3/tutorial/) | canonical language path | Python |
| [Automate the Boring Stuff](https://automatetheboringstuff.com/) | beginner projects | Python |
| [Pro Git](https://git-scm.com/book/en/v2) | Git reference | Start |
| [Missing Semester](https://missing.csail.mit.edu/) | shell and developer tooling | Start |
| [NumPy Learn](https://numpy.org/learn/) | arrays/numerical Python | Data |
| [pandas Getting Started](https://pandas.pydata.org/docs/getting_started/) | table workflows | Data |
| [PostgreSQL Tutorial](https://www.postgresql.org/docs/current/tutorial.html) | SQL foundations | Data |
